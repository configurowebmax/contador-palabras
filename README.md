# Contador de Palabras y Caracteres Gratis

Aplicación web gratuita para **contar palabras, caracteres, párrafos y tiempo de lectura** de tus textos.

## ✨ Características

- Conteo de **palabras, caracteres, párrafos y oraciones**.
- Caracteres **con y sin espacios**.
- **Tiempo de lectura** estimado (200 ppm).
- Actualización en tiempo real.

## 🚀 Uso

Escribe o pega tu texto y las métricas se actualizan automáticamente.
